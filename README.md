# Rooftop ETF Flow（天台ETF资金流）

> 版本：`v0.1.0` | 「天台工具（Rooftop Tools）」系列量化观察模块之一

基于**官方基金份额变动 × 单位净值 / 一级市场净申赎**口径，监控 A 股与美股主要宽基 ETF（按指数簇 Cluster 汇总）及行业/题材 ETF 按日（1D）、周（5D）、月（20D）、季（60D）的资金净流入/净流出，结合大盘点位与涨跌表现分析资金偏好、国家队护盘/减仓节奏与行业轮动主线。

## 核心特性

1. **真实资金流口径**：告别失真的二级市场大单统计，A 股直接对接上交所、深交所官方每日基金份额披露接口 + 天天基金单位净值，美股对接 ETFdb 一级市场净申赎数据 + Yahoo Finance 日线。
2. **宽基指数簇（Cluster）聚合**：将跟踪同一核心指数的旗舰 ETF（如沪深300簇、上证50簇、中证500/1000簇、中证A500簇、双创簇等）自动合并统计，穿透分流效应。
3. **结合大盘点位的智能复盘**：自动识别核心宽基在关键大盘点位上的“逆势护盘吸筹”、“增量共振”、“逢高兑现”等动作，测算正流入交易日加权买入点位锚，并生成四象限行业轮动分析与 Markdown 复盘报告（归档于 `docs/reports/`）。
4. **独立 Web 可视化看板**：FastAPI + SQLite + ECharts 5，支持 A股/美股切换、多周期切换、单只 ETF 历史趋势穿透、Web 端动态新增监控标的与盘前/盘后一键同步。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 同步数据并生成分析报告（盘后 / 盘前执行）
```bash
python sync_and_report.py --days 75
```
数据将存入 `data/rooftop_etf.db`，复盘报告输出至 `docs/reports/latest_analysis_report.md`。

### 3. 启动 Web 看板
```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```
浏览器访问 `http://127.0.0.1:8000` 即可打开看板。
