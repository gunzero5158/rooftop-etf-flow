# Rooftop ETF Flow（天台ETF资金流）

> 版本：`v0.2.2` | 「天台工具（Rooftop Tools）」系列量化观察模块之一

结合 **盘后官方基金份额净申赎** 与 **盘中实时资金流向（分行业 · 分题材）** 双模式监控 A 股与美股市场资金偏好、国家队动向及板块轮动主线。

## 核心特性

1. **双模式自由切换**：
   - **盘后份额流向（官方申赎）**：告别失真的二级市场大单统计，A 股直接对接上交所、深交所官方每日基金份额披露接口 + 天天基金单位净值，美股对接 ETFdb 一级市场净申赎数据 + Yahoo Finance 日线。
   - **⚡ 实时资金流向（行业 · 题材）**：
     - **A股实时**：覆盖同花顺/新浪全市场 90 大行业、精选概念题材（自动剔除通道与成分噪音标签），以及监控池 37 只 ETF 的内外盘主动买卖额、量比与 IOPV 实时折溢价；
     - **美股实时**：覆盖 20 大美股行业板块（`XLK/XLF/XLV/KRE/ITB/ITA/XME/XHB/IYT/KIE` 等）与 20 大热门题材（`SMH/SOXX/IGV/BOTZ/CIBR/URA/IBIT/KWEB/AIQ/PAVE/ICLN/BLOK` 等）的日内资金流模型（MFM）及领涨龙头股追踪，支持 30 秒自动刷新；
     - **四象限轮动矩阵**：默认提供 2×2 结构化轮动矩阵卡片（逆势抄底 / 主线共振 / 资金撤离 / 逢高兑现）并支持切换防重叠散点图，非交易时段自动标识“上一交易日/收盘定格”状态。
2. **宽基指数簇（Cluster）聚合**：将跟踪同一核心指数的旗舰 ETF（如沪深300簇、上证50簇、中证500/1000簇、中证A500簇、双创簇等）自动合并统计，穿透分流效应。
3. **结合大盘点位的智能复盘**：自动识别核心宽基在关键大盘点位上的“逆势护盘吸筹”、“增量共振”、“逢高兑现”等动作，测算正流入交易日加权买入点位锚，并生成四象限行业轮动分析与 Markdown 复盘报告（归档于 `docs/reports/`）。
4. **独立 Web 可视化看板**：FastAPI + SQLite + ECharts 5（采用 `zenith-quant` TradingView 暗黑 + 薄荷青视觉体系），支持 Web 端动态新增监控标的与盘前/盘后一键同步。

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 同步盘后数据并生成分析报告（盘后 / 盘前执行）
```bash
python sync_and_report.py --days 75
```
数据将存入 `data/rooftop_etf.db`，复盘报告输出至 `docs/reports/latest_analysis_report.md`。

### 3. 启动 Web 看板
```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000
```
浏览器访问 `http://127.0.0.1:8000` 即可打开看板。
